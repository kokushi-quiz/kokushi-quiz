クイズ公開ツール

HTMLファイルをGitHub Pagesで公開 → URLを発行
Step 1 　GitHub 設定
quiz-app kokushi-quiz study-quiz
⚠️ トークンはこのツール内のみで使用され、外部送信はされません。
取得方法: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate（repoにチェック）
Step 2 　HTMLファイルを選択
📂
ここにHTMLファイルをドロップ
または クリックしてファイルを選択（複数選択可）
Step 3 　公開する
✅ 公開完了！以下のURLでアクセスできます
💡 使い方のヒント
• URLをLINEやメールでiPhone/iPadに送ってSafariで開くと動作します
• GitHub PagesのURLは永続的に無料で使用できます
• ファイルを更新する場合は同じ手順で再アップロードしてください
